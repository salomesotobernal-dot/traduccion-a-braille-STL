Este código es traduce números y letras en español a braille de la siguiente manera; la función braille_dict incluye letras, numeros y espacio, la función verificar_caracteres revisa el texto y muestra en pantalla los caracteres que no tienen traducción, input permite que el usuario ingrese la frase y la pasa a minúsculas, print muestra la traducción en pantalla y por último verificación, llama la función para avisar si hubo caracteres no soportados.
